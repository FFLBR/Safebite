# Отложенная версия карты (Яндекс / OSM-поиск магазинов)

Файлы сохранены для возврата к Яндекс-карте позже. В приложение не подключены.

- store-map.tsx.txt — карта на Яндекс JS API v3 с геолокацией и счётчиками корзины
- yandex-maps.ts.txt — загрузчик Яндекс API через функцию yandex-maps-js
- nearby-stores.ts.txt — поиск магазинов рядом через Overpass (OpenStreetMap)
- safebite-app.tsx.txt — версия приложения с этими блоками
- index.css.txt — стили Яндекс-версии карты

Ключ YANDEX_MAPS_JS_API_KEY остаётся в Облаке; значения в файлах нет.
